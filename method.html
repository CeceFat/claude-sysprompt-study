方法與證據

一份講「文件怎麼變」的整理，如果自己不能被查核就沒有價值。 這一頁交代資料怎麼來、哪裡不可靠、以及本站在轉成網頁時重跑了哪些查核。

資料怎麼來

  1. 以 curl 抓取 overview 與 18 個子頁的 .md 原始檔（Mintlify 原始 MDX），不經任何摘要模型。
    curl -sL -H "Accept: text/markdown" https://platform.claude.com/docs/en/release-notes/system-prompts/<slug>.md
  2. 依每頁的 ## <日期> 標題與 Text only: ／ Text and images: 標籤，把 ```text 圍欄內文切成 34 個版本檔（分析矩陣取 32 欄）。Oct 22 2024 條目原文以字面 \n 表示換行，已正規化。
  3. 以 git diff --no-index -U0 --word-diff=plain 做 21 組逐字比對（同頁相鄰日期、同日兄弟模型、跨世代承接），輸出 [-舊-]{+新+} 格式。
  4. 以關鍵片語對 32 版做出現矩陣，PowerShell IndexOf(OrdinalIgnoreCase) 逐一比對，交叉驗證 diff 結論。

抓取時間 2026-09-07。evidence/sources/ 是官方頁面原文；versions/、diffs/、feature_matrix.txt 是分析產物。

七項文件品質警語

這些是官方文件本身的瑕疵，不是整理過程造成的。引用前先看一眼。

Q1　Haiku 3.5 的 text+images 變體，日期標籤不可信影響最大

該變體標在 2024-10-22 之下，內容卻寫著 The Claude 3 family currently consists of Claude Haiku 3.5, Claude Opus 3, Claude Sonnet 3.5, and Claude Sonnet 3.7、model string claude-3-7-sonnet-20250219、cutoff start of December 2024、網址 docs.claude.com。

座標〔Haiku 3.5 / 2024-10-22 / text+images〕　影響：該變體實為 2025-02 之後的 3.7 世代模板套用於 Haiku，日期標籤不可信。本站在版本表與矩陣中都把它排在第 12 位並加註。

開原文看這一段

Q2　2025-08-05 條目與 07-31 逐字相同

Sonnet 4 與 Opus 4 的 2025-08-05 條目與 2025-07-31 條目完全一致（diff 為空，本站已重跑確認）。

影響：08-05 只是 Opus 4.1 發布日的同步收錄，不是一次變更。把它當成「一次改版」會高估改版頻率。

Q3　網域被回溯改寫，URL 不能當年代證據

Haiku 3.5 的 text-only 變體已寫 support.claude.com／docs.claude.com，但同期的 Sonnet 3.5（2024-11-22）仍是 anthropic.com；claude.com 網域在其他頁首次出現於 2025-09-29。

影響：頁面曾被回溯做網域替換。用 URL 推斷條文年代會出錯。可在特徵矩陣搜 docs.anthropic.com 與 docs.claude.com 對照分布。

Q4　只有四個條目自己標了差異

只有 Sonnet 3.5 的 2024-09-09，以及 Sonnet 4.5、Haiku 4.5、Opus 4.5 的 2026-01-18，在頁首說明句中用 ** 標記與前版的差異。

影響：其餘差異必須自行 diff。這正是這份整理存在的理由。

Q5　Opus 4.6 的 election_info 失去格式

<election_info> 整段擠成一行，條列格式消失。

座標〔Opus 4.6 / 2026-02-05 / knowledge_cutoff〕　影響：顯示為手動貼回，不是流程產出。搭配它「刪除後又重現」的軌跡看，是分支手動維護的強證據。

Q6　Fable 5.1 頁面被 MDX 切成兩塊

該頁在 <example> 內含巢狀 ``` 圍欄，導致 MDX 把 prompt 切成兩個程式碼區塊。

影響：本站證據包已合併還原為單一 prompt。這是 34 個版本檔中唯一需要人工介入的一份，字數 4,267 是還原後的數字。

Q7　長期未修的錯字，佐證人手編修
  • as as、being being（Opus 4.1 → 2026-01-18 才修）
  • can't or won't with（Claude 4 全期）
  • crises（Opus 4.5 起）
  • Claude can instead treats（至 Opus 4.7）
  • the left of the right（Haiku 3.5）
  • National Alliance for Eating Disorder（Opus 4.8 才補 s）

影響：錯字能存活數個版本、跨越數個模型，佐證 prompt 是人手逐段編修並在分支間複製貼上，而不是由單一來源產生。
